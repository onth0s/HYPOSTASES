# Front 11 — Abductive Reasoning & Hypothesis Objects

Spec Ref: `misc/next-steps.md` Sections XI & XII

## Overview
Extends inverse inference from state estimation to explicit abductive reasoning — identifying the best explanations for observations and representing those explanations as explicit computational Hypothesis objects.

## Core Abductive Question
> "What explanation best accounts for these observations?"

## Hypothesis Object Structure
```
Hypothesis
├── identifier
├── description
├── assumptions
├── predictive_model
├── prior
├── likelihood
├── posterior
├── complexity
├── supporting_evidence
├── contradicting_evidence
└── confidence
```

## Epistemic Shift
Rather than maintaining only $P(\text{state})$, agents maintain probability distributions over competing explanatory models $H_1, H_2, H_3, \dots$

## Core State Constraint
Hypothesis objects evaluate predictive likelihoods against state histories generated by $\sigma = (c, w, g, \rho_{\text{ext}})$.
