# Front 05 — Institution Layer

Spec Ref: `misc/next-steps.md` Section V

## Overview
Institutions become explicit first-class entities rather than purely emergent behavioral outcomes of individual agent interactions.

## Institution Examples
- Governments
- Markets
- Guilds
- Corporations
- Courts
- Protocols
- Treaties

## Institution as Agent
Institutions may themselves operate as agents with:
- Goals
- Resources
- Governance rules
- Memory
- Authority
- Decision policies

## Core State Constraint
Institution entities are modeled as agents over primitive state $\sigma = (c, w, g, \rho_{\text{ext}})$ with additional authority and membership projections.
